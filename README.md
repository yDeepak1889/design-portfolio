# Richa Chaturvedi — Portfolio

Static HTML, CSS, and JS. No build, no dependencies.

## Local

```sh
python3 -m http.server 4173
```

Open http://localhost:4173

## Case studies

Each case study lives in `work/<slug>/index.html` with its own stylesheet in `css/case-study.css` and images under `assets/work/<slug>/`.

## GitHub Pages

Push to `main` deploys via GitHub Actions to **richadesigns.co**.
